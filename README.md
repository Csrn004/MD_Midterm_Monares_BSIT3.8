Center Record Management System

​
A command-line interface (CLI) application written in Dart designed to manage and look up records for both patients and staff members in a medical center or facility setting.

​This project demonstrates core Object-Oriented Programming (OOP) principles in Dart, including Abstraction, Inheritance, Polymorphism, Encapsulation, as well as the use of Mixins, Collections, and Exception Handling.

​Features
​Add Patient Records: Record patient details including unique ID, name, age, and ailment/condition.
​Add Staff Records: Record staff information including unique ID, name, job role, and monthly salary (formatted in PHP).
​Automated Timestamping: Every record is automatically assigned a formatted creation date and time using a Dart Mixin.
​View All Records: Display all stored records dynamically using polymorphic method execution.
​Fast ID Lookup: Search records instantly by ID using a hash-based lookup structure (Map).
​Input Validation & Exception Handling: Gracefully handles duplicate IDs and invalid input types (e.g., non-numeric entries for age or salary) without crashing.
